# PhantomCheck AI

## Quick Start
1. cd backend && cp .env.example .env (fill in API keys)
2. bash start.sh
3. cd ../frontend && npm install && npm run dev
4. Open http://localhost:5173

## API Docs
http://localhost:8000/docs
